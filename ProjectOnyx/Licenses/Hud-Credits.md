# HUD — credits

Onyx RP's status hexagons and vehicle HUD (v318) follow the look of Kane's NoPixel 4.0 inspired qb-hud
(https://github.com/rohKane/Kane-qb-hud-Nopixel-4.0-inspired, an edit of the QBCore hud, GNU General Public License v3.0).
Onyx draws them with its own code. The image files below come from other work and are shipped as separate files:

| Onyx file | Source | Licence |
|---|---|---|
| `Assets/Hud/seatbelt.png` | qb-hud `html/seatbelt.png`, unmodified | GNU GPL v3.0 (text: `lj-inventory-GPL-3.0.txt`, the same licence) |
| `Assets/Hud/voice.png` | qb-hud `html/speaking-head.svg`, the EmojiOne "speaking head" by Ranks.com (https://www.emojione.com), rendered to a white PNG | CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/) |
| `Assets/Hud/fuel.png` | Font Awesome Free 6.5.2 "gas-pump" by Fonticons, Inc. (https://fontawesome.com), rendered to a white PNG | CC BY 4.0 |
| `Assets/Hud/oil.png` | Font Awesome Free 6.5.2 "oil-can" by Fonticons, Inc., rendered to a white PNG | CC BY 4.0 |
| `Assets/Hud/gears.png` | Font Awesome Free 6.5.2 "gear", the same file as `Assets/Menus/icon_gear.png` | CC BY 4.0 |

The shapes are unchanged.
