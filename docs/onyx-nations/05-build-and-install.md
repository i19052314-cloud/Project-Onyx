# Установка ONYX RP: NATIONS & WAR от А до Я

> **Сразу главное.** В репозитории **только исходники**. Готового `OnyxNations.dll`
> нет, и потому «просто скопировать и играть» не получится. Нужно один раз
> собрать проект в Visual Studio — это занимает минут десять и делается один раз.
> Ниже — полностью по шагам, включая то, что делать с каждой ошибкой.

**Сложность:** обычная, как «собрать проект из GitHub». Ничего править в коде не
нужно, если только ворота не встанут боком (см. шаг 10).

> **Не хотите читать** — запустите `install.bat` из корня репозитория, он делает
> всё сам (раздел «Быстрый путь» ниже). Всё остальное — тот же процесс вручную
> с объяснениями и разбором ошибок.

---

## Быстрый путь: install.bat

Если вы хотите просто поставить мод, а не читать про сборку, — в корне
репозитория лежат два bat-файла:

| Файл | Что делает |
|---|---|
| `install.bat` | сам находит папку GTA V, сам копирует `ScriptHookVDotNet3.dll` из игры в `lib\shvdn3\`, сам собирает проект через MSBuild, раскладывает файлы по папкам и проверяет, что всё легло куда надо |
| `uninstall.bat` | снимает модуль; сохранения (`OnyxNations\Saves\`) не трогает, пока вы сами не скажете |

Двойной клик — и всё. **Visual Studio не нужна** — если MSBuild не найден,
скрипт собирает DLL компилятором из .NET Framework (подробнее в части 3.0).
Если папку с игрой он не нашёл, перетащите её мышкой на `install.bat` либо
передайте путь аргументом:

```bat
install.bat "D:\Games\Grand Theft Auto V"
```

Что он делает по шагам:

1. Ищет GTA V: аргумент → реестр Steam/Rockstar → 10 стандартных путей на
   дисках C:–H: → просит ввести путь руками. Проверяет, что внутри есть
   `GTA5.exe`; если нашёл только `GTA5_Enhanced.exe` — предупреждает, что это
   не та ветка.
2. Проверяет, что в папке игры есть `ScriptHookVDotNet3.dll`, `ScriptHookV.dll`,
   `dinput8.dll` и `ProjectOnyx\`. Про отсутствующее пишет, но идёт дальше
   (кроме SHVDN3 — без него останавливается, потому что и собрать, и запустить
   без него нельзя).
3. Копирует `ScriptHookVDotNet3.dll` из папки игры в `lib\shvdn3\` — то есть
   Часть 2 этого руководства вам делать уже не нужно. Заодно читает версию
   сборки и ругается, если это 3.9+ (ветка Enhanced).
4. Собирает `src\OnyxNations\OnyxNations.csproj` в Release. MSBuild ищет через
   `vswhere`, потом по стандартным путям VS 2022/2019. Если Visual Studio нет,
   а `bin\Release\OnyxNations.dll` уже лежит (вы собрали руками), — берёт его
   и спрашивает, надо ли пересобрать.
5. Перед записью делает резервную копию всего, что собирается затереть, в
   `<GTA>\OnyxNations\Backup\<дата-время>\`.
6. Копирует: DLL и ini в `scripts\`, семь XML в `OnyxNations\Data\`.
7. Проверяет каждый файл на месте и печатает список. Дальше — Часть 5.

Сообщения на экране — **на английском**: в bat-файле латиница, потому что
кириллица в консоли Windows зависит от кодовой страницы и на части систем
превращается в кракозябры. Основные фразы:

| Что он написал | Что это значит |
|---|---|
| `[ok] lib\shvdn3\ScriptHookVDotNet3.dll` | reference для сборки готов |
| `[warn] ProjectOnyx\ not found - module runs self-contained` | Onyx RP не найден в этой папке, мод всё равно встанет и будет работать сам по себе |
| `ERROR: ScriptHookVDotNet3.dll is not in the game folder` | не установлен ScriptHookVDotNet. Поставьте 3.6/3.7 (Часть 0) |
| `ERROR: no Visual Studio / MSBuild found` | собирать нечем — откройте проект в VS, Release → Ctrl+Shift+B, потом запустите `install.bat` снова: он подберёт готовую DLL |
| `ERROR: the build failed` | **пришлите мне красные строки целиком** — код ни разу не компилировался, ошибка ожидаема и чинится быстро |
| `INSTALLED.` | всё легло; проверок не провалено |
| `[MISS] ...` | файл не записался — обычно игра запущена или папка только для чтения |

Он ничего не удаляет: старые файлы уходят в `Backup\`, папка `Saves\` не
трогается вообще.

Ниже — тот же процесс вручную, с объяснениями и с разбором каждой ошибки.
Если `install.bat` споткнулся, идите сразу в Часть 3, там про сборку подробно.

## Часть 0. Что должно уже стоять и работать

| Что | Зачем | Откуда |
|---|---|---|
| **GTA V Legacy** (обычная, не Enhanced) | игра | Steam / Rockstar / Epic |
| **ScriptHookV** | загрузчик нативных хуков | dev-c.com |
| **ScriptHookVDotNet 3.x — линия Legacy (3.6 / 3.7)** | без него .NET-скрипты не грузятся | github.com/crosire/scripthookvdotnet |

> ⚠️ **Не берите ScriptHookVDotNet 3.9.** Он для ветки Enhanced. В README Onyx RP
> прямо сказано: Legacy — это 3.6/3.7, смешивать нельзя. Смешаете — скрипт
> молча не загрузится, и в логе SHVDN будет ругань на версию API.

## Часть 2. Положить ScriptHookVDotNet3.dll (для компиляции)

> Если вы запускаете `install.bat` (см. «Быстрый путь» выше), этот шаг он делает
> сам: копирует `ScriptHookVDotNet3.dll` из папки игры в `lib\shvdn3\` и
> проверяет версию. Читать дальше имеет смысл только для понимания.

Из **вашего уже рабочего** архива ScriptHookVDotNet (того, что лежит в папке
игры) возьмите `ScriptHookVDotNet3.dll` и скопируйте в:

```
Project-Onyx\lib\shvdn3\ScriptHookVDotNet3.dll
```

Там уже лежит файл-подсказка `PLACE_SHVDN3_REFERENCE_HERE.txt` — его можно
удалить или оставить, он ни на что не влияет.

> Этот файл нужен **только чтобы скомпилировать**. В саму сборку он не попадает
> и с модом не поставляется: в игре работает тот ScriptHookVDotNet, что уже
> стоит у вас в папке GTA.

Альтернатива, если не хотите ничего копировать:

```bat
msbuild src\OnyxNations\OnyxNations.csproj /p:Configuration=Release /p:SHVDN3Dir=C:\Путь\К\ScriptHookVDotNet\
```

## Часть 3. Собрать DLL

### 3.0. Visual Studio не обязателен

`install.bat` сначала ищет MSBuild (Visual Studio или бесплатные Build Tools), а
если его нет — берёт **`csc.exe` из .NET Framework**, тот самый, что лежит в

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe
```

Он есть на любом компьютере, где работает GTA V: ScriptHookVDotNet сам требует
.NET Framework 4.8. Проект нацелен на .NET Framework 4.8 и C# 7.3 — ровно то,
что этот компилятор умеет. Так что если вы запускаете `install.bat`, читать
дальше этой части не нужно: DLL соберётся сама.

Ниже — как собрать руками, если хотите.

### 3.1. Что нужно из Visual Studio

Если VS ещё нет: **Visual Studio 2022 Community** (бесплатная). При установке
отметьте галочку **«Разработка классических приложений .NET»**. Этого достаточно;
.NET Framework 4.8 targeting pack входит в неё.

### 3.2. Сборка

1. Откройте `Project-Onyx\src\OnyxNations\OnyxNations.csproj`.
2. Сверху выберите конфигурацию **Release** (не Debug).
3. Меню **Сборка → Собрать решение** (или `Ctrl+Shift+B`).
4. Ждите. Первая сборка — полминуты, не дольше.

Готовый файл:

```
Project-Onyx\src\OnyxNations\bin\Release\OnyxNations.dll
```

### 3.3. Если сборка упала

| Ошибка | Причина | Что делать |
|---|---|---|
| `ScriptHookVDotNet3.dll not found in '...\lib\shvdn3\'` | не положили reference | шаг 2 |
| `The type or namespace name 'GTA' could not be found` | reference положили, но не ту версию | нужен Legacy 3.6/3.7, не 3.9 |
| `The reference assemblies for .NETFramework,Version=v4.8 were not found` | не установлен targeting pack 4.8 | VS Installer → Изменить → отдельные компоненты → «Набор для настройки .NET Framework 4.8» |
| `Warning CS...` (жёлтые) | это предупреждения | не мешают, сборка всё равно успешна |
| Любая **красная** ошибка в коде | см. ниже | |

**Если видите красную ошибку в коде** — значит, я ошибся в чём-то, что не может
проверить структурная проверка (сигнатура метода, приведение типов). Пришлите
мне текст ошибки целиком — номер CS и название файла — и я исправлю. Это
ожидаемая ситуация: код ни разу не компилировался, потому что в моей среде нет
компилятора.

## Часть 4. Разложить по папке игры

Дальше `<GTA>` — это папка с `GTA5.exe` (например
`C:\Program Files\Rockstar Games\Grand Theft Auto V\`).

### 4.1. Скопируйте DLL и ini

```
<GTA>\scripts\OnyxNations.dll          ← из bin\Release\
<GTA>\scripts\OnyxNations.ini          ← из Project-Onyx\OnyxNations\
```

`scripts\` — та же папка, где уже лежат `ProjectOnyxDashboard.dll` и
`ScriptHookVDotNet3.dll`.

### 4.2. Скопируйте папку данных

Возьмите **всю** папку `Project-Onyx\OnyxNations\` и положите её **в корень
игры**, рядом с `ProjectOnyx\`:

```
<GTA>\
├── GTA5.exe
├── scripts\
│   ├── ScriptHookVDotNet3.dll
│   ├── ProjectOnyxDashboard.dll
│   ├── OnyxNations.dll          ← шаг 4.1
│   └── OnyxNations.ini          ← шаг 4.1
├── ProjectOnyx\                 ← не трогаем
└── OnyxNations\                 ← шаг 4.2
    ├── Data\
    │   ├── Nations.xml
    │   ├── Regions.xml
    │   ├── UnitTypes.xml
    │   ├── Armies.xml
    │   ├── Borders.xml
    │   ├── Parties.xml
    │   └── People.xml
    └── Saves\                   ← создастся само
```

> Папку `OnyxNations\` можно положить и внутрь `scripts\` — модуль найдёт её в
> обоих местах. Но **корень игры — правильный вариант**: при удалении мода
> достаточно удалить один DLL и одну папку.

### 4.3. Проверьте, что ничего лишнего не сделали

Вы **не** должны были:
- ничего менять внутри `ProjectOnyx\`;
- ничего удалять;
- класть что-либо в `update\` или `dlcpacks\`;
- править `gameconfig.xml` (он уже настроен под Onyx).

## Часть 5. Первый запуск

1. Запустите игру обычным способом.
2. Загрузите сохранение или начнёте новую игру.
3. Нажмите **F9**, чтобы убедиться, что Onyx включён (своя кнопка из README Onyx).
4. Подождите 10–15 секунд: модуль грузится вместе с остальными скриптами.
5. Нажмите **F6**. Должен открыться планшет.

### 5.1. Как понять, что всё работает

Откройте файл:

```
<GTA>\OnyxNations\onyx-nations.log
```

**Успешный старт выглядит так:**

```
=== ONYX RP: NATIONS & WAR - companion starting ===
assembly dir : C:\...\Grand Theft Auto V\scripts
game root    : C:\...\Grand Theft Auto V
module dir   : C:\...\Grand Theft Auto V\OnyxNations
data dir     : C:\...\Grand Theft Auto V\OnyxNations\Data (exists: True)
no save found - creating a new world
ready: 2 nations, 14 regions, 13 units, bridge = null (self-contained)
  RSA (rsa) - 10 regions, pop 2320000, treasury 45000000, army 1251
  FWSA (fzsa) - 4 regions, pop 566000, treasury 26000000, army 940
```

Цифры `army` могут отличаться на единицы — это боевая мощь, а не количество;
она зависит от духа, снабжения и генералов, которые в этот момент уже посчитаны.
Важны `2 nations, 14 regions, 13 units` и отсутствие `[ERROR]` выше.

**Видите `ready:` — всё работает.** Дальше можно играть.

### 5.2. Что ещё должно произойти

| Признак | Где |
|---|---|
| Панель «ГОСУДАРСТВА» в правом верхнем углу | экран, всегда |
| Тост «Граница: <регион> — RSA» при пересечении границы | экран |
| Файл `OnyxNations\Saves\world.json` появился | диск |
| Солдаты и техника рядом со столицей | мир (центр Лос-Сантоса, рядом с мэрией) |
| КПП с воротами и охраной | на границе (см. координаты ниже) |

### 5.3. Где именно стоят КПП

Шесть переходов, мировые координаты (X — запад↔восток, Y — юг↔север).
Ближайший к центру города — первый:

| Переход | X | Y | Ориентир |
|---|---|---|---|
| `downtown / zancudo` | 223 | 1654 | севернее центра Лос-Сантоса |
| `vinewood / zancudo` | −691 | 1902 | Вайнвуд-Хиллз, на север |
| `senora / zancudo` | 696 | 2607 | Гранд-Сенора |
| `chumash / vinewood` | −1666 | 1692 | Чумаш, побережье |
| `chumash / west_ls` | −2720 | −61 | западное побережье |
| `grapeseed / senora` | 2660 | 3082 | Грейпсид, северо-восток |

Подъезжайте не closer than ~200 м — пост материализуется сам и исчезнет, когда
вы уедете. Это не баг, так сделано специально: GTA не держит шесть КПП сразу.

## Часть 6. Управление

| Клавиша | Что делает |
|---|---|
| **F6** | открыть/закрыть президентский планшет |
| **← / →** | переключить экран планшета (7 штук) |
| **Enter** | действие текущего экрана |

**Экраны планшета:**

| Экран | Что показывает | Enter |
|---|---|---|
| 1. Сводка | нации, регионы, население | сохранить мир |
| 2. Армия | состав, сила, дух, снабжение, приказы | приказ 3 частям идти в ваш регион |
| 3. МИД | отношения, баланс сил, усталость | объявить войну / просить мира |
| 4. Бюджет | казна, ВВП, налог, инфляция, рейтинг | поднять налог на 2% |
| 5. Границы | переходы, режим, экипаж, повреждения | — |
| 6. Выборы | срок, рейтинг, опросы партий | влить 5 млн в кампанию |
| 7. Правительство | кабинет, командующие | закрыть вакансию лучшим кандидатом |

**Отладочные клавиши** (выключаются `DevTools=false` в ini):

| Клавиша | Действие |
|---|---|
| `NumPad1` / `NumPad2` | отдать текущий регион РСА / ФЗСА |
| `NumPad7` / `NumPad8` | объявить войну / просить мира |
| `NumPad9` | приказ частям идти в ваш регион |
| `NumPad0` | сохранить мир немедленно |

## Часть 7. Если не работает

Почти всё лечится чтением лога. Сначала откройте
`<GTA>\OnyxNations\onyx-nations.log`.

| В логе / на экране | Причина | Лечение |
|---|---|---|
| Лога нет вообще | скрипт не загрузился | проверить, что `OnyxNations.dll` в `scripts\`; проверить ScriptHookV и SHVDN |
| `missing config: ...\OnyxNations\Data\...` | папку данных положили не туда | шаг 4.2: нужна `<GTA>\OnyxNations\Data\` |
| `copy the OnyxNations folder into the GTA folder` | то же самое | шаг 4.2 |
| `Enabled=false in the ini - nothing is loaded` | выключено в настройках | в `OnyxNations.ini` поставить `Enabled=true` |
| `N config problem(s) - the module stays idle` | битый XML в Data | ниже строка `config: ...` скажет что именно; переустановите папку `OnyxNations\` |
| `the existing save could not be read...` | `world.json` повреждён | удалить `OnyxNations\Saves\world.json` — будет новый мир (бэкапы: `world.json.bak1`) |
| Планшет открывается, но вместо текста — квадраты | кириллица не в шрифте | в ini: `Language=en` |
| Скрипт грузится, но Onyx перестал работать | — | **невозможно по конструкции**: модуль не вызывает Onyx и не трогает его файлы. Проверьте, не задели ли вы что-то в `ProjectOnyx\` |
| Игра вылетает при старте | возможен конфликт версии SHVDN | проверить, что SHVDN именно Legacy 3.6/3.7 |

**Если ничего не помогло** — пришлите мне файл `onyx-nations.log` целиком. Он
написан так, чтобы отвечать на вопрос «почему не работает» без доступа к вашему
компьютеру.

## Часть 8. Удаление

Проще всего — `uninstall.bat` из корня репозитория: он снимет DLL,
ini и XML, а сохранения оставит (и спросит, если вы захотите стереть всё).

Вручную:

1. Удалить `<GTA>\scripts\OnyxNations.dll`
2. Удалить `<GTA>\scripts\OnyxNations.ini`
3. Удалить папку `<GTA>\OnyxNations\` (если хотите удалить и сохранённые миры)

Всё. Папка `ProjectOnyx\` остаётся нетронутой, Onyx RP работает как раньше.

```bat
cd Project-Onyx
```

## Часть 10. Первое, что проверить после запуска

Две вещи, которые я физически не мог проверить:

### 10.1. Ворота могут стоять боком

У каждого пропа в GTA своя локальная ось. Если `prop_gate_military_01` встал
перпендикулярно дороге, откройте:

```
<GTA>\OnyxNations\Data\Borders.xml
```

найдите строку с `prop_gate_military_01` и поменяйте `Heading="0"` на
`Heading="90"`. **Пересобирать DLL не нужно** — достаточно перезапустить игру
(или перезагрузить скрипты).

Правило: `Mode="Across"` — торцом к приезжающему, `Mode="Along"` — вдоль линии
границы. `Heading` — доворот поверх него.

### 10.2. Модели, которых нет в игре

Если какого-то пропа не окажется в файлах игры, он просто не появится, а в логе
будет строка:

```
border prop 'prop_xxx' is not in the game files - skipped
```
