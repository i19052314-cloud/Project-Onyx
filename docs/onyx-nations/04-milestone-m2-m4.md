# M2–M4 — границы, выборы, правительство

**Статус:** механики доказаны в исполняемой эталонной модели
(`tools/sim_reference.py`, 43 проверки), C# транскрипция сверена с эталоном
(`tools/check_parity.py`, 237 проверок). Компиляции в песочнице нет.

---

## 1. Границы (M2)

### Откуда берутся переходы

Переходы **не перечислены в конфиге**. Они выводятся из графа смежности
регионов: для каждой пары соседних регионов с разными владельцами пост ставится
на середине **общего ребра** двух полигонов. Добавили регион или сменили
владельца — граница перерисовалась сама; списка, который может устареть, нет.

Первая версия ставила пост в середине между центроидами. Это ошибка: ячейки
Вороного изогнуты, и на этой карте **2 перехода из 6 попали в третий регион** —
КПП оказывался в глубине страны, которая к границе отношения не имела. Тест
поймал это сразу (4/6), потому ищет именно попадание на ребро.

| Проверка в `sim_reference.py` | |
|---|---|
| каждый переход лежит на общем ребре двух регионов | 6/6 |
| переход не попадает в третий регион | 6/6 |
| при захвате региона граница перерисовывается | да |
| `Forward` — единичный вектор, `Side` к нему перпендикулярен | да |
| `Forward` всегда направлен из A в B | 6/6 |
| смещение по `Side` не сдвигает через границу | да |
| знак `Forward` определяет, в какой стране окажется проп | 42/42 |
| оборонительные сооружения стоят за линией, а не перед ней | да |

### Что происходит на посту

Отношения решают, что делает охрана (`Borders.xml`):

| Условие | Режим | Поведение |
|---|---|---|
| отношения ≥ `OpenAbove` (40) | открыт | пропускают |
| отношения ≥ `InspectAbove` (−20) | досмотр | останавливают, проверяют |
| иначе | закрыт | въезд запрещён |
| война | враждебен | открывают огонь |

Экипаж поста (`Manning`) растёт на `ManningPerDay`, когда рядом есть войска, и
падает на `DecayPerDayWithoutGarrison`, когда их нет. У перехода есть
`Damage` — обстрелянный пост перестаёт кого-либо останавливать и восстанавливается
только если хозяин удерживает обе стороны.

### Как раскладывается пост

Пост задаётся **относительно границы**, а не по мировым осям, więc одна и та же
раскладка читается и на границе север–юг, и на границе запад–восток:

| Атрибут | Смысл |
|---|---|
| `Forward` | метры вдоль направления движения (регион A → регион B) |
| `Side` | метры поперёк, вдоль линии границы |
| `Mode` | `Across` — проп стоит лицом к приезжающему; `Along` — вдоль линии границы; `Fixed` — без поворота |
| `Heading` | доворот в градусах поверх режима |
| `MinManning` | уровень экипажа, ниже которого проп не ставится |

Пост держит владелец **региона A**, поэтому отрицательный `Forward` — сторона
обороняющихся, положительный — подъезд. Граница — это серединный перпендикуляр
к отрезку между центроидами, поэтому знак `Forward` однозначно определяет, в
какой стране окажется проп. Это проверяется численно: **42/42** пропов попадают
на ту сторону, которую обещает знак, а пропы с `Forward = 0` остаются ровно на
линии (**18/18**, допуск 5 см на дистанциях ~1,5 км).

### Раскладка (имена пропов проверены в игре)

| Проп | Позиция | Режим | Экипаж |
|---|---|---|---|
| `prop_gate_military_01` | ворота, на самой линии | Across | ≥ 0.50 |
| `prop_sec_barrier_ld_01a` / `_02a` | барьеры по бокам от ворот | Along | ≥ 0.20 |
| `prop_sec_barier_04b` / `_02a` | вторая линия, за спиной обороны | Along | ≥ 0.45 |
| `prop_roadcone02a` ×2 | конусы на подъезде | Fixed | всегда |
| `prop_barrier_work01a` | щит перед воротами | Across | ≥ 0.10 |
| `prop_portacabin01` / `_02` | блокпосты за линией | Across | ≥ 0.35 / ≥ 0.60 |

Потерявший экипаж пост теряет ворота и будки — остаются только конусы.

### Экономия сущностей

GTA не держит стену через всю карту. Реальными объектами существуют только
`MaxBorderPosts` (2) ближайших переходов и не более `MaxBorderGuards` (8)
охранников. Каждая модель проверяется через `IS_MODEL_IN_CDIMAGE` **до** спавна:
неверное имя стоит одного отсутствующего пропа и одной строки в логе, а не
вылета.

## 2. Выборы (M3)

### Как считаются голоса

Доля партии — это её базовая популярность, сдвинутая **результатами правления**:

```
record = (рейтинг − 50)/200 + (настроение − 0.60)*0.20 − (безработица − 0.06)*1.20
         − max(0, инфляция − 0.05)*1.50 + (стабильность − 0.70)*0.15
         ± военный эффект (война сплачивает, но только пока её выигрывают)
         − штраф за скандал, если рейтинг < 25

доля = популярность ± ястребиный сдвиг (в войну плюс, в мир минус)
       + record (правящей партии) или + record*0.35 (оппозиции)
       + бонус действующего лица + деньги кампании (до +8 п.п., убывающая отдача)
       − штраф за радикальность налоговой программы
```

Явка растёт от злости и страха: довольный electorate не голосует.

### Что доказано численно

| Проверка | Результат |
|---|---|
| популярный президент (рейтинг 78) ведёт в опросах | 0.465 |
| непопулярный (рейтинг 30) отстаёт | 0.176 против 0.420 |
| та же партия при плохих делах теряет голоса | 0.465 → 0.176 |
| деньги кампании покупают голоса | 0.415 → 0.460 |
| кампанию нельзя профинансировать деньгами, которых нет | отклонено |
| лимит сроков снимает бонус действующего лица | 0.422 → 0.377 |
| по лимиту сроков баллотироваться нельзя | да |
| провалившее правительство выгоняют | `rsa_civic` → `rsa_labour` |
| пост действительно теряется | да |
| налоговая программа победителя двигает ставку | 0.240 → 0.268 (цель 0.320) |
| явка остаётся в заданных границах | 0.35..0.85 |
| доли всегда дают 100% | да |

### Один срок — 120 игровых дней

Пять игровых суток проходят за реальную минуту, значит президент отвечает перед
избирателями каждые 24 минуты игры, из них последние 5 — кампания. Достаточно
долго, чтобы успеть что-то сделать, достаточно быстро, чтобы это увидеть.

Никаких «магических» дат: счётчик суток срока ведёт **только** `StepElection`.
Первая версия дублировала его в тике часов — и выборы просто перестали
наступать.

Реальный прогон за 2 года (6 выборов на страну): власть дважды меняла руки
(«Сан-Андреас прежде всего» выигрывала с потерей поста, потом «Гражданский
союз» возвращался), в Федерации побеждали «Единство Федерации» и «Лига
фронтира».

## 3. Правительство (M4)

### Назначения

Пул кандидатов — `People.xml`: 38 человек, у каждого компетентность, лояльность,
жалование и фракция. Министра можно назначить и уволить.

Компетентность **не украшение**. Она напрямую входит в финансовый, транспортный,
оборонный, внутренний и дипломатический бонусы нации; навык генерала — в боевой
бонус всей армии. Правительство из удобных людей measurably хуже управляет: это
видно в бюджете и на поле боя.

У каждого назначения цена сверх жалования:
- кандидат из другой фракции стоит единства кабинета (−0.04 стабильности);
- увольнение стоит доверия остальных министров (тем больше, чем лояльнее
  уволенный) и рейтинга;
- назначение отклоняется, если казна не потянет 30 дней жалования.

Уже сидящие министры не попадают в пул доступных — нельзя «назначить»
министра, который и так работает.

### Экран планшета

`F6` → семь экранов (`←`/`→`): сводка, армия, МИД, бюджет, границы, выборы,
правительство. `Enter` на каждом делает реальное действие:

| Экран | Действие `Enter` |
|---|---|
| Сводка | запись в лог о сохранении по запросу |
| Армия | приказ трём ближайшим частям идти в регион, где вы стоите |
| МИД | объявить войну / просить мира |
| Бюджет | поднять налог на 2% |
| Границы | показать режим ближайшего перехода |
| Выборы | влить 5 млн в кампанию |
| Правительство | закрыть первую вакансию лучшим доступным кандидатом |

## 4. Сохранения

Добавлено к уже сохранённому: срок, число сроков, правящая партия, глава
государства, дни кампании, оба предвыборных фонда, явка и победитель
прошлых выборов — плюс экипаж и повреждение каждого перехода.

Геометрия границы **не сохраняется**: она выводится из регионов, поэтому
обновлённый `Regions.xml` не оставит устаревший пост. Исчезнувший переход
(два региона теперь одна страна) сообщается, а не роняет загрузку.

## 7. Чего здесь ещё нет

*   **Пропы проверены в игре по именам, но не по взаимному расположению:**
    у каждого может быть своя локальная ось, поэтому `Heading` в `Borders.xml`
    — доворот, который, возможно, придётся подкрутить на 90° для конкретного
    пропа. Это одна цифра в конфиге, движок пересобирать не нужно.
*   **Патрули:** патрульная машина (`police4`) ставится при экипаже ≥ 0.5.
    Маршрутов патрулирования (объезд границы) пока нет.
*   **Реакция NPC на пересечение:** игрока останавливают и выдают сообщение;
    гражданские NPC на границу не реагируют — это ждёт API Playerz.
*   **Кандидаты не стареют и не уходят:** пул статичен. Смертей, отставок по
    здоровью и скандалов нет.
*   **Проверка в игре:** FPS, стабильность, совместимость с Onyx — только после
    сборки.
