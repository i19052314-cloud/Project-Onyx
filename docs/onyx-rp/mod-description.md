# ONYX RP — описание сборки

Готовые тексты: короткий — для карточки мода, полный — для страницы/README.

## Короткое (карточка, 2–3 строки)

> **Onyx RP** — офлайн-ролевая надстройка над GTA V (Legacy, Story Mode): телефон,
> инвентарь, «третий глаз», бизнесы, жильё, ограбления, гонки, банды, мэрия,
> полиция и тюрьма, NPC-«Playerz» с ИИ-диалогом на русском и английском.
> В этой сборке сверху добавлены **NATIONS & WAR** — политика, экономика и война
> двух государств на карте Сан-Андреаса — и **Onyx Admin**, панель администратора.

## Что такое Onyx RP

Это не отдельная игра, а большой мод на GTA V: он превращает одиночную игру в
ролевую песочницу. Ядро — нативный `ProjectOnyx.asi`, вокруг него работают
компаньоны на ScriptHookVDotNet (телефон, панель автомобиля) и мост к LSPDFR.

**Что внутри (по конфигурации и ассетам проекта):**

| Блок | Что даёт игроку |
|---|---|
| **Playerz** | NPC с ИИ-диалогом: текст и голос, роли, отношения, звонки, чат, эмоции, визуальный контекст |
| **Телефон** | смартфон в игре: контакты, СМС, приложения, знание города |
| **Инвентарь** | 615 иконок предметов, база предметов, крафт, лут-таблицы |
| **«Третий глаз»** | подсветка объектов и персонажей, как в детективных режимах |
| **Экономика игрока** | бизнесы и портфель, доходы, заказы, жильё и аренда, магазины, банкоматы |
| **Работа** | гражданские работы, доставка еды, экзамены и лицензии в DMV |
| **Криминал** | ограбления домов, магазинов, фабрик, «Тихого океана», инкассаторские машины, наркозоны |
| **Гонки** | 84 трассы: машины, мотоциклы, грузовики, вертолёты, самолёты, газонокосилки |
| **Правопорядок** | преступления, EMS, задержание, адвокаты, суд, тюрьма |
| **Банды и территории** | фракции, зоны влияния, войны за кварталы |
| **Госуслуги** | мэрия, налоги, лицензии, штрафы |
| **GameStation 5** | игровая консоль внутри игры: 45 игр в оболочке WebView2 |
| **Свой интерфейс** | рисованный UI: 173 PNG меню, HUD, спидометр, мед-интерфейс |

Языки: русский и английский (переключение в настройках мода).

## Что добавлено в этой сборке

### 1. NATIONS & WAR — государства, политика, война

Отдельный скрипт-компаньон. Сан-Андреас разделён на **14 регионов** (по почтовой
карте проекта), и на них живут **два государства**:

- **Республика Сан-Андреас** (RSA) — за неё играет президент, то есть вы;
- **Федерация Западного Сан-Андреаса** (FZSA) — её ведёт ИИ: воюет, торгует,
  заключает мир и следит за своим рейтингом.

| Система | Что работает |
|---|---|
| **Территории** | 14 регионов, население, площадь, стратегическая ценность, контроль, оккупация, спорные зоны |
| **Армии** | 8 типов соединений (пехота, мотострелки, танки, артиллерия, авиация, вертолёты, спецназ, военная полиция), 10 стартовых частей, сила, дух, снабжение, опыт |
| **Война** | наступление, оборона, оккупация, потери, усталость от войны, «плюс к рейтингу, пока побеждаешь» |
| **Границы** | КПП на стыках регионов: посты, стража, режимы (открыт / досмотр / закрыт / враждебный), повреждения; захват региона передвигает границу |
| **Экономика** | казна, ВВП, налог, четыре статьи расходов, инфляция, безработица, настроение, стабильность, коррупция |
| **Политика** | 6 партий, рейтинг, выборы каждые 120 игровых дней, лимит 2 срока, фонд кампании, оппозиция и возвращение во власть |
| **Правительство** | кабинет из 7 министерств, кандидаты с компетентностью и лояльностью, генералы, зарплаты, задания министрам |
| **ИИ противника** | утилитарная модель: агрессия, осторожность, меркантилизм; держит армию, торгуется, идёт на мир |
| **Сохранения** | автосохранение, 5 резервных копий, ручное сохранение из планшета |

**Планшет президента** — 7 экранов, каждая строка — реальный приказ:

| Экран | Enter | Shift+Enter |
|---|---|---|
| Сводка мира | сохранить мир | — |
| Армия | выбранный отряд → в ваш регион | вся армия |
| МИД | война / мир с выбранной страной | санкции |
| Бюджет | +2% к выбранной строке | −2% |
| Границы | режим выбранного перехода | — |
| Выборы | 5 млн в фонд кампании | 1 млн |
| Правительство | назначить министра | уволить; «+ генерал» |

### 2. Onyx Admin — панель администратора

Режим бога, все защиты (огонь/взрыв/ближний бой/столкновения), бесконечные
патроны, «никогда не разыскивается», выдача 42 видов оружия, полное здоровье и
броня, снятие розыска, спавн 20 моделей транспорта (машины, броневики, танк,
вертолёты, самолёт, катера), починка и удаление машины, телепорт к метке.

## Управление

| Клавиша | Действие |
|---|---|
| **F9** | включить Onyx RP |
| **F10** | настройки Onyx |
| **0** | телефон |
| **I** | инвентарь |
| **N** | push-to-talk (голос Playerz) |
| **T** | чат с NPC |
| **F7** | эмоции |
| **F5** | панель администратора |
| **F8** | планшет президента (меняется в `OnyxNations.ini`, можно с модификатором: Ctrl+Alt+F8) |
| **← →** | экраны планшета |
| **↑ ↓** | строка планшета |
| **Enter / Shift+Enter** | действие / второе действие |
| **NumPad 1/2/7/8/9/0** | отладочные: отдать регион, война, мир, приказ, сохранить |

Все клавиши переопределяются в `OnyxNations.ini` и `OnyxAdmin.ini`.

## Техническая часть

| Параметр | Значение |
|---|---|
| Игра | GTA V **Legacy** (`GTA5.exe`), Story Mode, офлайн |
| Загрузчик | ScriptHookV + ScriptHookVDotNet **3.6 / 3.7** |
| Платформа | .NET Framework 4.8, x64 |
| Ядро Onyx | нативный `ProjectOnyx.asi` (закрытый) |
| Наши модули | `OnyxNations.dll`, `OnyxAdmin.dll` — отдельные скрипты, **Visual Studio не требуется** для сборки |
| Конфигурация | 121 XML геймплея + INI настроек |
| Ассеты | 1233 файла (PNG/TTF/MP3), ~218 МБ папка `ProjectOnyx` |
| Совместимость | Enhanced-версия GTA V не поддерживается сознательно |

**Принцип сосуществования.** Оба наших модуля работают *рядом* с Onyx, а не внутри
него: вызывают только публичный API ScriptHookVDotNet, пишут только в свои папки
(`OnyxNations\`, `OnyxAdmin\`) и трогают только те объекты, которые создали сами.
Файлы, память и сохранения Onyx не изменяются — поэтому модули нельзя «сломать»
ядром и наоборот.

## Установка

1. Установите Onyx RP по его инструкции (`ProjectOnyx.asi`, `scripts\`,
   `ProjectOnyx\`), запустите игру и нажмите **F9** — мод должен ожить.
2. В папке репозитория: `install.bat "путь к GTA V"` — соберёт и поставит
   `Nations & War`.
3. `build-admin.bat "путь к GTA V"` — соберёт и поставит админ-панель.
4. В игре: **F9** (включить Onyx) → **F8** (планшет) → **F5** (админка).

Удаление — `uninstall.bat`: снимает только наши файлы, сохранения остаются.

## Честные ограничения

- **Два государства, а не двадцать.** Карта разбита на 14 регионов; это осознанный
  масштаб, при котором ещё работает производительность GTA.
- **Армия — это числа плюс ближайшие отряды.** Реальными педами существуют только
  2 отряда и 12 солдат рядом с игроком, остальное — стратегическая карта. GTA не
  держит полноценную армию.
- **Планшет Onyx (клавиша M) не расширяется.** Его интерфейс находится внутри
  закрытого `ProjectOnyx.asi`; исходников ядра в репозитории нет, поэтому наш
  планшет — отдельный, на своей клавише.
- **Нет денег и инвентаря Onyx из админки.** Это его внутреннее состояние; запись
  извне — испорченное сохранение. Возможно только через официальный API Onyx.
- **Готовых DLL в репозитории нет** — только исходники и скрипты сборки.
