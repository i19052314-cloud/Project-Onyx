ScriptHookVDotNet3.dll goes here — for compiling only.
=====================================================

Copy ScriptHookVDotNet3.dll from your **GTA V Legacy** ScriptHookVDotNet
package (the 3.6/3.7 API line) into this folder, then build
src\OnyxNations\OnyxNations.csproj.

Nothing from this folder is copied into the build output and nothing ships
with the mod: the game loads its own ScriptHookVDotNet runtime. This file only
exists so the C# project can resolve `Script` / `Game` / `Function.Call`.

Do NOT mix the Enhanced (3.9) runtime in here — Onyx RP's README states the
Legacy line is 3.6/3.7 and the two must not be mixed.

Alternative: build without copying anything:

    msbuild src\OnyxNations\OnyxNations.csproj /p:SHVDN3Dir=C:\Path\To\SHVDN3\
